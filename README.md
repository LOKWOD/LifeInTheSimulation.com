# LifeInTheSimulation.com

Static editorial website for **Life in the Simulation**.

## What is included

- 32 evidence-aware essays across reality, mind, AI, attention and systems
- 33 practical field and decision guides
- 18 short Signals
- 26-term glossary
- curated topic hubs for simulation theory, AI, attention and privacy
- interactive, local-only thought experiments
- responsive dark/light design
- article table of contents and reading progress
- search and category filtering
- RSS, complete sitemap, article and breadcrumb structured data, manifest and custom 404
- unique 1200px social cards and three Article image aspect ratios per publication
- visible editorial bylines, publishing policy and a comprehensive automated SEO audit
- no framework or client-side application dependency

## Publishing

The site is published from the `main` branch through GitHub Pages and uses the custom domain `lifeinthesimulation.com`. The publishing workflow rebuilds the archive, applies the durable SEO normalization layer, generates social imagery and blocks publication if the site-wide audit finds an error.
