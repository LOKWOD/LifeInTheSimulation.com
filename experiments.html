03

TWO MINUTES

The sensory reset

  1. Name five things you can see without using category words.
  2. Identify four separate sounds.
  3. Notice three points of physical contact.
  4. Take two slow breaths without changing anything else.
  5. Name one fact that is true in this room right now.
04

TEN MINUTES

The interface inventory

  1. List the five interfaces you used most today.
  2. Write the behavior each one made easiest.
  3. Write the behavior each one made invisible or difficult.
  4. Change one default before tomorrow.
05

ONE CONVERSATION

The unrendered person

  1. Choose someone you mostly encounter through posts or messages.
  2. Speak live or meet in person.
  3. Ask about something absent from their public profile.
  4. Notice what the representation left out.

THE RULE

An experiment should let reality push back.

If an exercise can only confirm what you already believe, it is a ritual. Useful experiments create the possibility of surprise, correction or a changed behavior.
